# Euphoria

Discord bot written in Python using `discord.py`.

The project is designed as a modular Discord bot with support for extensions, scheduled tasks, database access, logging, permissions and external process interaction through a FIFO pipe.

## Requirements

* Python 3.10+
* Discord Bot Token
* Linux/Unix environment recommended
* `discord.py`
* `APScheduler`

## Installation

Clone the repository:

```bash
git clone https://github.com/Azgard3334/bot-euphoria.git
cd bot-euphoria
```

Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

> If a `requirements.txt` is added to the project, dependencies should be installed with `pip install -r requirements.txt` instead.
